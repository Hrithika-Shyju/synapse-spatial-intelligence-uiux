## 📌 Project Overview
**Synapse** is a spatial intelligence and sensemaking platform designed to help investigators and intelligence analysts explore complex information and understand relationships across fragmented investigative data—including **People, Organizations, Financial Transactions, Communication Records, and Legal Documents**.

By combining an **Infinite Investigation Canvas**, semantic relationship mapping, contextual inspection, and **Micro, Macro, and Meta** semantic zoom levels, Synapse bridges the gap between structured documentation and open-ended visual exploration.

## 🧭 Core UX & Spatial Architecture Summary
* **Primary Target Persona:** Alex Morgan (Investigative Analyst)
* **Competitor Benchmarking:** Palantir Gotham, Linkurious, Miro, and FigJam
* **Five Workspace UI Zones:**
  1. **Top Navigation Bar:** Global controls, search, undo/redo, and workspace settings.
  2. **Investigation Sidebar:** Investigation navigation, entity categories, saved groups, and data sources.
  3. **Infinite Investigation Canvas:** Node-based workspace with semantic links, entity clusters, and pan/zoom navigation.
  4. **Context Inspector:** Detailed metadata, source records, and relationship inspection for selected entities.
  5. **Floating Canvas Toolbar:** Quick access to Select, Pan, Add Entity, Connect, Group, and Zoom tools.
* **Semantic Zoom Hierarchy:** **Micro** (detailed entity inspection), **Macro** (relationship exploration), and **Meta** (high-level cluster and network overview).
