## 📌 Project Overview
**Synapse** is an AI-augmented spatial workspace designed to help researchers, strategists, and knowledge workers synthesize unstructured qualitative data. By combining an infinite 2D canvas with semantic auto-clustering and automated sensemaking summaries, Synapse eliminates manual sticky-note sorting and prevents context loss.
