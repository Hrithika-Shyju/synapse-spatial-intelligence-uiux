# Core User Flows

## Project: Synapse – Spatial Intelligence & Sensemaking Canvas

### Overview

Core user flows describe how users interact with Synapse to transform scattered information into organized and meaningful knowledge.

The three primary user journeys are:

1. **Ingestion:** Adding unorganized notes and information to the canvas.
2. **Sensemaking:** Using AI-powered synthesis to identify patterns, clusters, and relationships.
3. **Synthesis & Output:** Reviewing the organized canvas and exporting an AI-generated executive brief.

---

## Flow 1: Dropping Messy Notes onto the Canvas (Ingestion)

**Goal:** Allow users to quickly collect and place scattered research information onto a flexible spatial canvas.

### Step-by-Step Journey

1. **Open Workspace:** The user opens Synapse and creates a new workspace for a research topic.
2. **Access Canvas:** A blank spatial canvas appears.
3. **Add Information:** The user adds research notes, text snippets, observations, and key findings.
4. **Arrange Notes:** The user freely moves and positions notes anywhere on the canvas.
5. **Review Content:** The user checks the collected information before beginning the synthesis process.

**User Outcome:** All scattered research information is collected in one workspace, ready for analysis.

**Key UI Elements:**
- Create Workspace button
- Empty canvas
- Add Note button
- Sticky notes / information cards
- Drag-and-drop interaction

---

## Flow 2: Clicking "Synthesize Canvas" (Sensemaking)

**Goal:** Help users identify meaningful patterns and relationships within their collected information through AI-assisted organization.

### Step-by-Step Journey

1. **Initiate Synthesis:** The user clicks the **Synthesize Canvas** button.
2. **AI Processing:** Synapse analyzes the notes and their content.
3. **Automatic Clustering:** Related notes are grouped into meaningful clusters based on their semantic similarities.
4. **Generate Semantic Links:** The system identifies potential relationships between different notes and displays visual connections.
5. **Review Suggestions:** The user explores the suggested groups and connections.
6. **Refine Canvas:** The user can accept, reject, or manually adjust the AI-generated organization.

**User Outcome:** Unorganized notes become a structured visual knowledge map, helping users identify connections and patterns.

**Key UI Elements:**
- Synthesize Canvas button
- AI processing indicator
- Automatically grouped note clusters
- Visual connection lines
- AI-generated labels or group headings
- Accept / Reject / Edit controls

---

## Flow 3: Zooming Out and Exporting an AI Executive Brief (Synthesis & Output)

**Goal:** Help users understand the bigger picture and convert their organized research into a concise, shareable summary.

### Step-by-Step Journey

1. **Zoom Out:** The user zooms out to view the complete canvas and understand how different clusters are connected.
2. **Explore Knowledge Map:** The user reviews the relationships, major themes, and key findings.
3. **Generate Executive Brief:** The user clicks the **Generate Executive Brief** option.
4. **AI Summarization:** Synapse generates a concise summary based on the organized research content.
5. **Review Brief:** The user reviews the generated summary and makes any necessary edits.
6. **Export Document:** The user exports the final executive brief in a supported format.

**User Outcome:** The user receives a clear overview of the research and a shareable summary of the key findings.

**Key UI Elements:**
- Zoom controls
- Full canvas overview
- Generate Executive Brief button
- AI-generated summary panel
- Edit / Review options
- Export button

---

## Overall User Journey

| Stage | User Action | System Response | Outcome |
|---|---|---|---|
| Ingestion | Adds scattered notes | Displays notes on canvas | Information collected |
| Sensemaking | Clicks Synthesize Canvas | Groups related notes and suggests links | Connected knowledge map |
| Synthesis & Output | Zooms out and exports brief | Generates a concise summary | Shareable executive brief |

## Conclusion

These three core user flows represent the main interaction journey within Synapse. The product aims to simplify the transition from scattered research information to organized visual knowledge and meaningful outputs through spatial interaction and AI-assisted sensemaking.
